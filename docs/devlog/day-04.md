# Day 04. Application 클래스와 객체 수명

2026-09-08 (KST)

## 실습 내용

실행 단계를 `Application` 클래스로 옮기고 `main()`에서 객체를 만들어 `app.Run()`을 호출했어요. 생성자와 소멸자가 호출되는 순서를 로그로 살펴봤습니다.

## 확인한 내용

`public`은 접근 범위를 정해요. `Run()`은 직접 호출하고, 생성자와 소멸자는 객체의 수명에 맞춰 실행돼요.
